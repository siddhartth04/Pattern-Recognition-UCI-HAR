# Before submitting

These are unresolved author/venue decisions, not missing experimental results disguised as completed work.

1. Select a conference and track that accepts this empirical contribution. Verify its actual deadline, scope, page limit, required template, and supplementary-material rules.
2. Have the real authors read the code and paper, verify the claims, and take responsibility for the submission. Add names, affiliations, emails and contributions for a non-anonymous submission; preserve anonymity if required.
3. Review the AI-assistance statement against the venue's current policy. Do not list an AI as an author or claim human verification that has not happened.
4. Apply the venue's exact IEEE variant, paper size and page limit. The delivered file uses generic IEEEtran conference formatting; a particular conference may differ.
5. Review dataset redistribution terms and preserve notices. If the venue accepts only code, distribute download scripts rather than uploading all data unnecessarily.
6. If required, obtain and personally inspect a similarity report through an authorized institutional service. No detector score is promised.
7. Follow any venue-specific PDF validation, copyright and registration requirements through the official submission system.
8. Submit only after the actual authors approve. No submission, payment or external upload has been performed by this project.
